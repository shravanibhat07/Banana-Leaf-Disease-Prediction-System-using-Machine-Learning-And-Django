## Banana-Leaf-Disease-Prediction-System-using-Machine-Learning-And-Django
Machine Learning based Banana Leaf Disease Prediction System developed using Django and Scikit-learn. The project predicts banana leaf diseases using multiple machine learning models and provides real-time predictions through an interactive web interface. Random Forest achieved the highest accuracy of 55-65%.


## Features

* Real-time banana leaf disease prediction
* Interactive Django web application
* Multiple ML model comparison
* High accuracy prediction system

## Technologies Used

* Python
* Django
* Scikit-learn
* Pandas
* NumPy

## Models Used

* Logistic Regression
* Decision Tree
* Random Forest
* KNN

## Result

Random Forest achieved the highest accuracy of 55-65%.
